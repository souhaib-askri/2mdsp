# كراس عمل تطبيقي: احتراف مكتبة Pandas في 3 مراحل
## دليلك الشامل لتحليل ومعالجة البيانات في بايثون
### (1. الإنشاء • 2. التعامل والتحويل • 3. الاستخراج والتصدير)

---

### أهداف كراس العمل:
يقدم هذا الدفتر مساراً تدريبياً تطبيقياً ومباشراً للتعامل مع البيانات الجدولية (Tabular Data) باستخدام مكتبة **Pandas** عبر ثلاث محطات رئيسية:
1. **المرحلة الأولى: الإنشاء (Data Creation)**: بناء السلاسل (`Series`) وإطارات البيانات (`DataFrames`) من القواميس والقوائم ومصفوفات NumPy وقراءة الملفات الخارجية (CSV, JSON).
2. **المرحلة الثانية: التعامل والمعالجة (Data Manipulation)**: فحص البيانات، معالجة القيم المفقودة، هندسة الخصائص، العمليات الموجهة، التجميع الإحصائي (`groupby`)، والدمج العلائقي (`merge`).
3. **المرحلة الثالثة: الاستخراج والتصدير (Data Extraction)**: التحديد والتقطيع (`loc`, `iloc`)، التصفية بالاستعلامات الشرطية (`query`)، الجداول المحورية (`pivot_table`)، وتصدير النتائج النهائية.

### 2.2 تنظيف وتعويض القيم المفقودة (Imputation)

```python
# أخذ نسخة آمنة من البيانات لتفادي تعديل الأصل
جدول_نظيف = جدول_الموظفين.copy()

# حساب الوسيط الحسابي للراتب والمتوسط لتقييم الأداء
وسيط_الراتب = جدول_نظيف["الراتب_الأساسي"].median()
متوسط_التقييم = جدول_نظيف["تقييم_الأداء"].mean()

print(f"تعويض الراتب المفقود بالقيمة الوسيطة : {وسيط_الراتب:.2f} دينار")
print(f"تعويض التقييم المفقود بالمتوسط الحسابي: {متوسط_التقييم:.2f}")

# تطبيق التعويض عبر .fillna()
جدول_نظيف["الراتب_الأساسي"] = جدول_نظيف["الراتب_الأساسي"].fillna(وسيط_الراتب)
جدول_نظيف["تقييم_الأداء"] = جدول_نظيف["تقييم_الأداء"].fillna(متوسط_التقييم)

# التأكد من خلو الجدول من أي قيم مفقودة
print(f"إجمالي القيم المفقودة المتبقية: {جدول_نظيف.isna().sum().sum()}")
جدول_نظيف
```

### 2.3 هندسة الخصائص والعمليات الموجهة (Feature Engineering & Vectorization)

```python
# حساب الأقدمية بالسنوات بناءً على تاريخ مرجعي (2026-10-20)
تاريخ_اليوم = pd.to_datetime("2026-10-20")
جدول_نظيف["الأقدمية_بالسنوات"] = ((تاريخ_اليوم - جدول_نظيف["تاريخ_التوظيف"]).dt.days / 365.25).round(1)

# استخراج الاسم الأول ومعالجة النصوص
جدول_نظيف["الاسم_الأول"] = جدول_نظيف["الاسم"].str.split(" ").str[0]

# عملية شرطية موجهة لحساب المكافأة السنوية: مكافأة مضاعفة لمن تقييمهم >= 90
جدول_نظيف["المكافأة_السنوية"] = np.where(
    جدول_نظيف["تقييم_الأداء"] >= 90,
    جدول_نظيف["الراتب_الأساسي"] * 1.5,
    جدول_نظيف["الراتب_الأساسي"] * 0.5
)

print("--- الجدول بعد إضافة الأعمدة المحسوبة الجديدة ---")
جدول_نظيف[["الاسم", "القسم", "الأقدمية_بالسنوات", "الراتب_الأساسي", "تقييم_الأداء", "المكافأة_السنوية"]]
```

### 3.1 التحديد المرجعي: الفارق بين `loc` و `iloc`

- **`loc`**: يعتمد على **التسميات والأسماء** وعناوين الأعمدة والشروط البولينية.
- **`iloc`**: يعتمد حصراً على **المواقع الرقمية الصحيحة** للفهارس (من 0 إلى n-1).

```python
# 3.1.1 التحديد بالمواقع الرقمية iloc: أول 3 صفوف وأول 4 أعمدة
عينة_رقمية = جدول_نظيف.iloc[0:3, 0:4]
print("--- استخراج باستخدام iloc (المواقع 0:3 صفوف, 0:4 أعمدة) ---")
عينة_رقمية
```

```python
# 3.1.2 التحديد بالأسماء والشروط loc: موظفو قسم 'علم البيانات' مع أعمدة محددة
عينة_شرطية = جدول_نظيف.loc[جدول_نظيف["القسم"] == "علم البيانات", ["الاسم", "الراتب_الأساسي", "تقييم_الأداء"]]
```

### 3.2 التصفية الشرطية المتقدمة واستعلامات `.query()`
