## 1. البيانات الجدولية ومكانة Pandas في علم البيانات (Slides 1 - 4)

### أ. البيانات الجدولية (Tabular Data) (Slide 4)
تحتل البيانات الجدولية مكانة مركزية في كافة مراحل ومشاريع علم البيانات (**Data Science**). تُعرّف البيانات الجدولية بأنها بيانات منظمة ومصفوفة بدقة في **صفوف (Rows)** و **أعمدة (Columns)**:
* **كل صف (Row / Observation)**: يمثل مشاهدة أو عينة إحصائية فريدة مستقلة بذاتها (مثل: مرشح رئاسي معين في سنة انتخابية محددة).
* **كل عمود (Column / Feature / Attribute)**: يمثل خاصية أو متغيراً يصف تلك المشاهدة (مثل: الحزب السياسي للمرشح، عدد الأصوات الشعبية، النسبة المئوية المحققة).

### ب. لماذا مكتبة Pandas؟ (Slide 3)
* توفر **Pandas** هياكل بيانات مرنة وعالية الأداء مع ترسانة واسعة من الدوال الرياضية والإحصائية المصممة لجعل تحليل وتعديل البيانات سريعاً وبديهياً وتعبيرياً (**Fast, flexible, and expressive**).
* تم بناؤها بالكامل فوق مكتبة **NumPy** مع ميزة ثورية: **المحاور المعنونة والموسومة (Labeled Axes)**. هذه التسميات تمنع أخطاء اختلال المحاذاة التلقائية (**Alignment Errors**) أثناء العمليات الحسابية وتسمح بالتعامل مع البيانات غير المتجانسة والقيم المفقودة (**Missing Data - NaN**) بكفاءة متناهية.

## 2. الهياكل الأساسية: السلاسل (Series) وإطارات البيانات (DataFrames) (Slides 5 - 12)

تتكون مكتبة Pandas من مكونين بنائيين رئيسيين:
1. **Series**: هيكل بيانات أحادي البعد مصفوفي يحمل فهرساً معنوناً (`Index`).
2. **DataFrame**: هيكل بيانات ثنائي البعد مصفوفي يمتلك فهارس للصفوف وتسميات للأعمدة.

```python
import pandas as pd

```

### أ. بنية السلسلة (Series) وخصائصها (Slide 6 - 7)
* السلسلة عبارة عن مصفوفة أحادية البعد (**1D Array**) تحتوي على قيم من نفس نوع البيانات (**Homogeneous Data**).
* ترتبط كل قيمة بمفتاح أو تسمية فريدة تُعرف بـ **الفهرس (Index)**.
* يمكن الوصول بشكل مستقل إلى مصفوفة الفهارس عبر الخاصية `s.index`، ومصفوفة القيم الخام عبر الخاصية `s.values`:

```python
import pandas as pd

# إنشاء سلسلة افتراضية (Slide 6)
s = pd.Series(["welcome", "to", "data 100"])

print("الفهرس الافتراضي:", s.index)
# RangeIndex(start=0, stop=3, step=1)

print("مصفوفة القيم:", s.values)
# array(['welcome', 'to', 'data 100'], dtype=object)
```

#### بناء السلسلة بفهرس مخصص وتعديله (Slide 7):
يمكن تمرير قائمة مخصصة من التسميات لتمثيل الفهرس أثناء الإنشاء، كما يمكن إعادة تعيين الفهرس مباشرة في أي وقت لاحق:

```python
# إنشاء سلسلة بفهارس مخصصة:
s = pd.Series([-1, 10, 2], index=["a", "b", "c"])
print(s.index)
# Index(['a', 'b', 'c'], dtype='object')

# تعديل الفهرس بعد الإنشاء:
s.index = ["first", "second", "third"]
print(s.index)
# Index(['first', 'second', 'third'], dtype='object')

print(s)
# first     -1
# second    10
# third      2
# dtype: int64
```

---

### ب. آليات الاستعلام والتحديد في السلسلة (Selection in Series) (Slides 8 - 11)
تتيح السلسلة ثلاثة أنماط رئيسية لاستخراج البيانات:
1. **تسمية فردية (Single Label)** (Slide 9):
   استخدام اسم الفهرس مباشرة بين معقوفين لإرجاع القيمة العددية الفردية:
   ```python
   s = pd.Series([4, -2, 0, 6], index=["a", "b", "c", "d"])
   val = s["a"]
   print(val) # 4
   ```
2. **قائمة تسميات (List of Labels)** (Slide 10):
   تمرير قائمة من الفهارس بين قوسين مربعين مضاعفين `s[["a", "c"]]` لإرجاع سلسلة فرعية مصغرة:
   ```python
   sub_s = s[["a", "c"]]
   print(sub_s)
   # a    4
   # c    0
   # dtype: int64
   ```
3. **شرط التصفية والقناع البولياني (Boolean Masking)** (Slide 11):
   تطبيق مقارنة منطقية على السلسلة لتوليد سلسلة بوليانية متناظرة، ثم استخدامها لتصفية القيم التي تحقق الشرط:
   ```python
   # الخطوة 1: توليد القناع البولياني
   mask = s > 0
   print(mask)
   # a     True
   # b    False
   # c    False
   # d     True
   # dtype: bool

   # الخطوة 2: تطبيق القناع لاستخراج القيم الموجبة
   positive_values = s[s > 0]
   print(positive_values)
   # a    4
   # d    6
   # dtype: int64
   ```

### ب. تركيب محدد المواقع بالتسميات: `.loc` (Slide 26 - 27)
يعتمد المعامل `.loc` على **تسميات المحاور (Labels)**:
$$\text{df.loc}[\text{row\_labels}, \text{column\_labels}]$$

> [!important] قاعدة وسائط `.loc` (Slide 27)
> كل وسيط من وسيطي `.loc` (سواء للصفوف أو الأعمدة) يمكن أن يكون:
> 1. **قيمة تسمية مفردة (Single Label)**.
> 2. **قائمة من التسميات (List of Labels)**.
> 3. **تقطيعاً بالتسميات (Slice of Labels)**: ويتميز بكونه **شاملاً للطرف الأيمن (Inclusive of right bound)**.
> 4. **قناعاً بوليانياً (Boolean Mask)**.
> * إذا تم تمرير وسيط واحد فقط، تطبقه بايثون على الصفوف وتفترض الرمز `:` لجميع الأعمدة.

### ج. أمثلة الاستخراج التفصيلية عبر `.loc` (Slides 28 - 32)

#### 1. استخراج قيمة فردية محددة (Slide 28):
```python

# استخراج الأصوات الشعبية للصفوف 87 و 25 و 179
```

## 6. استخراج البيانات: التحديد بالمواقع الرقمية عبر `.iloc` (Slides 33 - 40)

### أ. تركيب محدد المواقع بالمؤشرات العددية: `.iloc` (Slide 34 - 35)
كلمة `.iloc` اختصار لـ (**Integer Location**)، وتتعامل حصراً مع الترتيب والمواقع الرقمية الصحيحة للعناصر (بدءاً من 0 حتى $N-1$):
$$\text{df.iloc}[\text{row\_integer\_indices}, \text{col\_integer\_indices}]$$

> [!warning] الفارق الحاسم في التقطيع (Slicing):
> عند استخدام التقطيع الرقمي مع `.iloc` (مثل `0:3`)، يكون **الطرف الأيمن مستثنى ومستبعداً تماماً (Exclusive of right bound)** تماماً مثل دالة `range(start, stop)` في بايثون، على عكس التقطيع بالتسميات في `.loc` الذي يشمل الطرف الأخير.

---

### ب. أمثلة الاستخراج التفصيلية عبر `.iloc` (Slides 36 - 39)

#### 1. استخراج عنصر مفرد بموقعه المطلق (Slide 36):
```python
# العنصر في الصف رقم 0 والعمود رقم 1
val = elections.iloc[0, 1]
print(val) # 'Andrew Jackson'
```

#### 2. استخراج صفوف رقمية لعمود رقمي محدد (Slide 36):
```python
# الصفوف ذات المؤشرات 1 و 2 و 3 في العمود رقم 1
series_iloc = elections.iloc[[1, 2, 3], 1]
print(series_iloc)
```

#### 3. استخراج تقاطع صفوف وأعمدة رقمية (Slide 37):
```python
# الصفوف 1 و 2 و 3 للأعمدة 0 و 1 و 2
sub_matrix = elections.iloc[[1, 2, 3], [0, 1, 2]]
print(sub_matrix)
```

#### 4. تقطيع الأعمدة بالمدى الرقمي (Slide 38):
```python
# الصفوف 1 و 2 و 3 والأعمدة من 0 إلى 2 (المجال 0:3 يستثني العمود 3):
range_df = elections.iloc[[1, 2, 3], 0:3]
print(range_df)
```

#### 5. سحب جميع الصفوف لمدى من الأعمدة (Slide 39):
```python
all_rows_slice = elections.iloc[:, 0:3]
```

### ج. مقارنة منهجية بين `.loc` و `.iloc`: متى نفضل كلاً منهما؟ (Slide 40)

| وجه المقارنة | محدد التسميات `.loc` | محدد الأرقام `.iloc` |
| :--- | :--- | :--- |
| **أساس الاستخراج** | التسميات الموسومة (Labels) | المؤشرات الصحيحة (0-based Integers) |
| **سلوك التقطيع `a:b`** | يشمل الطرف الأيمن $b$ (**Inclusive**) | يستبعد الطرف الأيمن $b$ (**Exclusive**) |
| **الأمان ضد التغيرات** | **أكثر أماناً وموثوقية**: إذا تغير ترتيب الأعمدة في مصدر البيانات، يظل الكود صحيحاً | حساس جداً؛ أي تغيير بترتيب الأعمدة يعطي بيانات خاطئة |
| **المقروئية الأكاديمية** | واضحة جداً: `elections.loc[:, ["Year", "Result"]]` | غامضة تتطلب حفظ أرقام الأعمدة: `elections.iloc[:, [0, 4]]` |
| **حالات الاستخدام المثلى** | التصفية الشرطية والاستعلام بأسماء الحقول | استخراج إحصائيات المواقع (مثل استخراج الوسيط عبر الصف الأوسط) |

## 8. الاستخراج الحساس للسياق عبر الأقواس المربعة `[]` (Slides 41 - 46)

تعتبر الأقواس المربعة `[]` شائعة جداً في لغة بايثون للاختصار، لكنها **حساسة للسياق (Context-Dependent)**، حيث تقبل وسيطاً واحداً فقط ويتغير سلوكها بناءً على نوع ذلك الوسيط:

```
                          ┌── تسمية فردية 'col' ───────► Series
                          ├── قائمة تسميات ['c1', 'c2'] ─► DataFrame
وسيط واحد فقط داخل [ ] ───┼── تقطيع أرقام [3:7] ────────► صفوف (Exclusive)
                          └── قناع بولياني [mask] ─────► تصفية الصفوف
```

### أ. استخراج عمود كسلسلة (Slide 43):
```python
# تمرير اسم عمود مفرد يرجع Series:
s_cand = elections["Candidate"]
print(type(s_cand)) # <class 'pandas.core.series.Series'>
```

### ب. استخراج عمود كـ DataFrame عبر الأقواس المزدوجة (Slide 43):
```python
# تمرير قائمة تحتوي على اسم العمود يرجع DataFrame ذو عمود واحد:
df_cand = elections[["Candidate"]]
print(type(df_cand)) # <class 'pandas.core.frame.DataFrame'>
```

### ج. استخراج قائمة أعمدة (Slide 44):
```python
# تمرير قائمة تسميات:
df_multi = elections[["Year", "Candidate", "Result"]]
```

### د. تقطيع الصفوف عبر الأرقام داخل `[]` (Slide 45):
```python
# استخراج الصفوف من الموقع 3 إلى الموقع 6 (الموقع 7 مستثنى):
rows_slice = elections[3:7]
```
> [!warning] ملاحظة دقيقة حول التقطيع بـ `[]`
> حتى لو كانت تسميات الفهرس أرقاماً صحيحة، فإن التقطيع العددي داخل `[]` يُفسر دائماً كمواقع رقمية صحيحة (بأسلوب `.iloc`) وتكون حدوده مستثناة من اليمين.

### هـ. تمرير قناع بولياني لتصفية الصفوف (Slide 46):
```python
# استخراج صفوف سنة 2008 مباشرة:
res_2008 = elections[elections["Year"] == 2008]
```

## 9. الأقنعة البوليانية المركبة والمعاملات البتية (Bitwise Operators) (Slides 47 - 51)

عند دمج عدة شروط منطقية في Pandas، **يُمنع استخدام الكلمات المفتاحية العادية `and` و `or` و `not`**، لأنها تقيم الحقيقة لكامل الكائن ككتلة واحدة مما يسبب خطأ `ValueError`. بدلاً من ذلك، نستخدم **المعاملات البتية (Bitwise Operators)** التي تنفذ العملية عنصراً بعنصر على مصفوفات الشروط:

| الرمز | الاستخدام في بايثون | المعنى المنطقي |
| :---: | :---: | :---: |
| `~` | `~p` | النفي المنطقي (**NOT**) |
| `&` | `p & q` | العطف المنطقي (**AND**) |
| `\|` | `p \| q` | الفصل المنطقي (**OR**) |
| `^` | `p ^ q` | الفصل الحصري (**XOR**: أحدهما صحيح وليس كلاهما) |

> [!danger] إلزامية الأقواس الدائرية `( )` (Slide 48)
> تملك المعاملات البتية (`&` و `|`) في بايثون أسبقية تنفيذ أعلى من معاملات المقارنة (`==`, `>`, `<`). لذلك، **يجب إلزامياً وضع كل شرط بين قوسين مستقلين**، وإلا سينهار البرنامج:
> ```python
> # خطأ فادح:
> # elections[elections["Year"] == 2008 | elections["%"] > 60] 
> 
> # صحيح وإلزامي:
> elections[(elections["Year"] == 2008) | (elections["%"] > 60)]
> ```

### أمثلة الاستعلامات المعقدة:
#### 1. استخراج المرشحين الديمقراطيين أو الجمهوريين بعد عام 1900 (Slide 50):
```python
query_result = elections.loc[
    (
        ((elections['Party'] == 'Democratic') | (elections['Party'] == 'Republican')) &
        (elections['Year'] > 1900)
    ),
    ['Year', 'Party', '%']
]
```

#### 2. استكشاف ما حدث في انتخابات عام 1992 (Slide 51):
```python
elections_1992 = elections[elections['Year'] == 1992]
print(elections_1992)
# يُظهر هذا الاستعلام المنافسة الشهيرة بحضور المرشح المستقل روس بيرو (Ross Perot)
# الذي حصد 18.9% من الأصوات الشعبية مؤثراً على توازن الحزبين.
```

## 10. خصائص وإدارة الفهارس (Index Manipulation) (Slides 52 - 56)

### أ. الفهارس غير الرقمية وغير الفريدة (Slides 52 - 53)
* ليس بالضرورة أن يكون الفهرس أرقاماً متسلسلة (0, 1, 2)؛ بل يمكن أن يكون نصياً مثل أسماء الأشخاص أو التواريخ.
* ليس بالضرورة أن تكون قيم الفهرس فريدة (**Non-unique indices**)؛ فقد يحمل أكثر من صف نفس قيمة الفهرس إذا تم تعيين عمود متكرر القيم كفهرس للجدول.

### ب. تحديد وتغيير الفهرس عبر `set_index()` (Slide 54)
```python
# تعيين اسم المرشح كفهرس رئيسي لإطار البيانات:
elections = elections.set_index("Candidate")
print(elections.head(3))
# الآن يمكن استخدام اسم المرشح مباشرة مع .loc:
# elections.loc["Barack Obama"]
```

### ج. استعادة الفهرس الافتراضي عبر `reset_index()` (Slide 55)
```python
# استرجاع الفهرس الرقمي الافتراضي وإعادة عمود "Candidate" إلى خانة الأعمدة العادية:
elections = elections.reset_index()
```

## 11. بدائل التصفية البوليانية المتقدمة والموجزة (Slides 57 - 61)

عند كتابة شروط مطولة تحتوي على خيارات متعددة بواسطة `|`، يصبح الكود متراكماً وصعب الصيانة:
```python
# أسلوب طويل ومعقد (Slide 60):
babynames[
    (babynames["Name"] == "Bella") |
    (babynames["Name"] == "Alex") |
    (babynames["Name"] == "Narges") |
    (babynames["Name"] == "Lisa")
]
```

### البدائل الذكية والأكثر إيجازاً في Pandas:
#### 1. الدالة `.isin()` (Slide 61):
تتحقق مما إذا كانت قيمة العنصر تنتمي إلى قائمة معطاة، وترجع سلسلة بوليانية مباشرة:
```python
names = ["Bella", "Alex", "Narges", "Lisa"]
clean_filter = babynames[babynames["Name"].isin(names)]
```

#### 2. دوال معالجة النصوص `.str.startswith()`:
تصفية الأسماء بناءً على بادئة نصية أو تعبير نمطي:
```python
# اختيار كافة الأسماء التي تبدأ بحرف 'B':
b_names = babynames[babynames["Name"].str.startswith("B")]
```
