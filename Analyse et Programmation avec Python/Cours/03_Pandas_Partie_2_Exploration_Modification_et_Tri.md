## 2. استكشاف خصائص وأبعاد إطار البيانات (Slides 4 - 13)

### أ. استخراج الفهارس والأبعاد (Slide 4)
* `df.index`: يرجع تسميات الصفوف.
* `df.columns`: يرجع تسميات الأعمدة.
* `df.shape`: يرجع أبعاد الجدول على شكل زوج مرتب: `(عدد الصفوف, عدد الأعمدة)`.

---

### ب. الفرق بين `.shape` و `.size` (Slide 5)
يحدث خلط متكرر بين الخاصيتين:
* **`.shape`**: تمثل **أبعاد المصفوفة** كزوج مرتب (أو ثلاثي)، حيث:
  $$\text{shape} = (\text{عدد الصفوف } N, \text{ عدد الأعمدة } M)$$
* **`.size`**: يمثل **العدد الإجمالي للخلايا والعناصر** في الجدول بالكامل، ويساوي حاصل ضرب الصفوف في الأعمدة:
  $$\text{size} = N \times M$$

#### مثال عملي من شريحة المحاضرة (مجموعة بيانات `babynames`):
```python
# عدد الصفوف 407,428 وعدد الأعمدة 5:
print(babynames.shape)
# (407428, 5)

# الحجم الكلي للخلايا في الذاكرة:
print(babynames.size)
# 2037140
# التحقق الرياضي: 407,428 × 5 = 2,037,140 عنصراً
```

### ج. التكامل مع مكتبة NumPy (Slide 6)
تستند هياكل Pandas إلى مصفوفات NumPy، مما يسمح بتطبيق كافة دوال NumPy الرياضية مباشرة على السلاسل والأعمدة العددية:

```python
import numpy as np

# استخراج تكرارات الاسم 'Yash':
yash_count = babynames.loc[babynames["Name"] == "Yash", "Count"]

# حساب المتوسط الحسابي عبر NumPy:
mean_val = np.mean(yash_count)
print("المتوسط:", mean_val) # 17.142857142857142

# حساب القيمة العظمى عبر NumPy:
max_val = np.max(yash_count)
print("الحد الأقصى:", max_val) # 29
```

### د. دوال الاستكشاف والتلخيص المدمجة (Built-In Methods) (Slides 7 - 12)

#### 1. دالة الإحصاء الوصفي `.describe()` (Slide 8):
تحسب ملخصاً إحصائياً شاملاً يتضمن: العدد (`count`)، المتوسط (`mean`)، الانحراف المعياري (`std`)، القيمة الصغرى (`min`)، الربيعيات الإحصائية (25%، 50% أو الوسيط، 75%)، والقيمة العظمى (`max`).
```python
babynames.describe()
```
> [!note] ملاحظة هامة:
> تقوم الدالة `.describe()` افتراضياً بتلخيص **الأعمدة العددية فقط**، وتتجاهل الأعمدة النصية ما لم يتم تحديد `include='all'`.

#### 2. حساب تكرار القيم الفريدة عبر `.value_counts()` (Slide 9):
ترجع سلسلة مرتبة تنازلياً تحتوي على عدد مرات ظهور كل قيمة فريدة في العمود:
```python
# حساب تكرار كل اسم في قاعدة البيانات:
name_counts = babynames["Name"].value_counts()
print(name_counts.head(5))
```

#### 3. المعاينة العشوائية المنضبطة عبر `.sample()` (Slide 10):
بدلاً من قراءة أول 5 صفوف عبر `.head()` (التي قد تكون مرتبة زمنياً أو منحازة ولا تمثل توزيع البيانات الحقيقي)، توفر الدالة `.sample()` أخذ عينات عشوائية ممثلة:
```python
# أخذ عينة عشوائية مكونة من صف واحد (افتراضياً n=1):
babynames.sample()

# أخذ عينة من 5 صفوف مع إمكانية التكرار (Sampling with replacement):
babynames.sample(5, replace=True)
```
> [!tip] الفرق بين المعاينة مع الإرجاع وبدون إرجاع:
> * `replace=False` (الافتراضي): أخذ عينة بدون إرجاع؛ لا يمكن للصف الواحد أن يظهر أكثر من مرة في العينة.
> * `replace=True`: أخذ عينة مع الإرجاع؛ يمكن لنفس الصف أن يُسحب عدة مرات.

#### 4. استخراج القيم الفريدة عبر `.unique()` (Slide 12):
ترجع مصفوفة NumPy تحتوي على القيم الفريدة دون تكرار:
```python
unique_names = babynames["Name"].unique()
print("عدد الأسماء الفريدة:", len(unique_names))
```

### هـ. تسلسل الدوال والعمليات (Method Chaining) (Slide 11)
تتيح Pandas ربط عدة عمليات تتابعية في تعبير واحد سلس. ولتنظيم الكود على عدة أسطر وجعله مقروءاً، يتم وضعه بين قوسين دائريين `( )`:

```python
# تسلسل العمليات في سطر واحد:
sample_subset = babynames.sample(5).iloc[:, 2:]

# تسلسل متعدد الأسطر مع التصفية والمعاينة والتقطيع:
result = (
    babynames[babynames["Year"] == 2000]
    .sample(4, replace=True)
    .iloc[:, 2:]
)
```

## 3. تعديل وإدارة الأعمدة (Adding, Modifying, Dropping) (Slides 14 - 20)

### أ. إضافة عمود جديد (Slide 14)
يتم إنشاء عمود جديد بإسناد سلسلة جديدة بنفس الطول أو تعبير مترافق:
```python
# حساب طول كل اسم وإضافته كعمود جديد:
babynames["name_lengths"] = babynames["Name"].str.len()
```

### ب. تعديل عمود موجود (Slide 15)
يمكن تعديل كامل العمود أو استخدام `.loc` لاستهداف صفوف معينة:
```python
# تعديل كامل العمود بطرح 1 من كل طول:
babynames["name_lengths"] = babynames["name_lengths"] - 1

# الأسلوب الموصى به برمجياً للتعديل الدقيق:
babynames.loc[:, "name_lengths"] = babynames["name_lengths"] - 1
```

### ج. إعادة تسمية الأعمدة عبر `.rename()` (Slide 16)
نمرر قاموساً يربط الاسم القديم بالاسم الجديد:
```python
# تغيير اسم العمود من "name_lengths" إلى "Length":
babynames = babynames.rename(columns={"name_lengths": "Length"})
```

### د. حذف الأعمدة والصفوف عبر `.drop()` وسلوك النسخ (Slides 17 - 19)
تحذف الدالة `.drop()` الصفوف افتراضياً (`axis="rows"` أو `axis=0`). ولحذف الأعمدة، **يجب إلزامياً تحديد المحور `axis="columns"` أو `axis=1`**:
```python
# حذف عمود "Length":
babynames = babynames.drop("Length", axis="columns")
```

> [!danger] فخ عدم تطبيق التعديلات (DataFrame Copies & Immutability) (Slide 18)
> لا تقوم دالة `.drop()` بتعديل إطار البيانات الأصلي في مكانه، بل تُرجع **نسخة جديدة ومعدلة** من الجدول!
> إذا قمت بكتابة:
> ```python
> babynames.drop("Length", axis="columns")
> ```
> فإن العمود **لن يُحذف** من المتغير `babynames`، وسيتفاجأ المطور بأن الجدول ظل كما هو!
> **الحل الإلزامي**: إعادة الإسناد لتحديث المتغير:
> ```python
> babynames = babynames.drop("Length", axis="columns")
> ```

## 4. ترتيب البيانات: الاستراتيجيات الثلاث لـ `.sort_values()` (Slides 21 - 25)

### أ. الترتيب الأساسي عبر `.sort_values()` (Slide 21)
تُستخدم الدالة لترتيب إطار البيانات أو السلسلة. وعند تطبيقها على جدول كامل، يجب تحديد العمود المراد الترتيب وفقه عبر المعامل `by`:
```python
# ترتيب تنازلي حسب عمود التكرار "Count":
sorted_df = babynames.sort_values(by="Count", ascending=False)

# ترتيب سلسلة نصية مباشرة:
sorted_names = babynames["Name"].sort_values()
```
> [!important] انتقال الفهارس مع الصفوف:
> عند إعادة ترتيب الصفوف، **تنتقل تسميات الفهرس (Index) الأصلية مع صفوفها** دون إعادة ترقيم، مما يحافظ على تكامل البيانات وهوية كل مشاهدة.

---

### ب. ترتيب البيانات وفق قيمة محسوبة (Sorting by Computed Values) (Slides 22 - 25)
إذا أردنا ترتيب الجدول وفق مقياس مشتق (مثل: طول الاسم)، توجد ثلاثة مناهج برمجية متدرجة الكفاءة:

#### المنهج 1: إنشاء عمود جديد والترتيب وفقه ثم حذفه (Slide 23):
المنهج التقليدي المباشر:
```python
babynames["name_lengths"] = babynames["Name"].str.len()
babynames_sorted = babynames.sort_values(by="name_lengths", ascending=False)
babynames_sorted.head(5)
```

#### المنهج 2: استخدام المعامل `key` مع دالة مجهولة `lambda` (Slide 24):
المنهج الأكثر احترافية ونظافة في الكود؛ حيث يطبق المعامل `key` الدالة أثناء خطوة المقارنة والترتيب مؤقتاً دون إضافة أعمدة جديدة إلى الجدول:
```python
sorted_by_len = babynames.sort_values(
    by="Name", 
    key=lambda x: x.str.len(), 
    ascending=False
).head(5)
```

#### المنهج 3: استخدام دالة مخصصة مع `.map()` للترتيب بحساب تكرار مقاطع نصية (Slide 25):
عندما تكون دالة القياس معقدة، نعرّف دالة بايثون مستقلة، ونطبقها عبر `.map()` ثم نرتب البيانات:
```python
# دالة تحسب عدد مرات ظهور المقطعين 'dr' و 'ea' في الاسم
def dr_ea_count(string):
    return string.count('dr') + string.count('ea')

# تطبيق الدالة عبر map وتخزين النتيجة وترتيب الجدول
babynames["dr_ea_count"] = babynames["Name"].map(dr_ea_count)
top_dr_ea = babynames.sort_values(by="dr_ea_count", ascending=False).head(5)
```

## 6. ترسانة دوال التحويل المتقدمة (Advanced Transformations) (Slides 26 - 37)

تستعرض الشرائح من 27 إلى 37 الأدوات التسع الأساسية للتحويلات الهندسية في Pandas:

### 0. العمليات المتجهة (Vectorized Operations) (Slide 27)
يجب دائماً تفضيل العمليات المتجهة الحسابية والمنطقية الأصلية على الحلقات التكرارية اليدوية، لأنها تنفذ على مستوى كود C المتصل في الذاكرة:
```python
df = pd.DataFrame({
    "price": [10, 20, 15],
    "quantity": [2, 3, 4]
})

df["total"] = df["price"] * df["quantity"]
df["discounted"] = df["total"] * 0.90
df["large_order"] = df["total"] >= 50
print(df)
#    price  quantity  total  discounted  large_order
# 0     10         2     20        18.0        False
# 1     20         3     60        54.0         True
# 2     15         4     60        54.0         True
```

### 1. الدالة `apply()`: منطق مخصص على مستوى الصفوف أو الأعمدة (Slide 28)
تُستخدم عندما يعتمد الحساب على **عدة أعمدة في آن واحد**:
* `axis=1`: تمرر كل **صف كائن Series** إلى الدالة.
* `axis=0`: تطبق الدالة على كل **عمود ككل**.

```python
df = pd.DataFrame({
    "name": ["Ali", "Sara", "Omar"],
    "salary": [5000, 4000, 6000],
    "experience": [3, 5, 7]
})

# حساب مكافأة تعتمد على الراتب وسنوات الخبرة معاً:
df["bonus"] = df.apply(
    lambda r: r["salary"] * 0.10 if r["experience"] >= 5 else r["salary"] * 0.05,
    axis=1
)
print(df)
#    name  salary  experience  bonus
# 0   Ali    5000           3  250.0
# 1  Sara    4000           5  400.0
# 2  Omar    6000           7  600.0
```

### 2. الدالة `map()`: مطابقة وتحويل قيم السلسلة (Slide 29)
تُستخدم لتحويل عناصر عمود واحد، ومثالية جداً للبحث في القواميس واستبدال القيم:
```python
df = pd.DataFrame({
    "name": ["Ali", "Sara", "Omar"],
    "grade": ["A", "B", "A"]
})

grade_points = {"A": 90, "B": 80, "C": 70}
df["points"] = df["grade"].map(grade_points)
print(df)
#    name grade  points
# 0   Ali     A      90
# 1  Sara     B      80
# 2  Omar     A      90
```
> [!warning] القيم غير المطابقة:
> أي قيمة في السلسلة لا تجد مفتاحاً مطابقاً لها في القاموس، يتم استبدالها تلقائياً بالقيمة المفقودة `NaN`.

### 3. الدالة `query()`: التصفية الاستعلامية النصية (Slide 30)
تتيح تصفية الصفوف بكتابة شرط استعلامي نصي أنيق بدون تكرار كتابة اسم إطار البيانات:
```python
df = pd.DataFrame({
    "name": ["Ali", "Sara", "Omar"],
    "salary": [5000, 4000, 6000],
    "experience": [3, 5, 7]
})

# تصفية برمجية بالشرط النصي:
result = df.query("salary >= 5000 and experience >= 5")
print(result)
#    name  salary  experience
# 2  Omar    6000           7

# لاستخدام متغير خارجي من بايثون، نضع قبله الرمز @:
min_exp = 4
result_ext = df.query("experience >= @min_exp")
```

### 4. الدالة `transform()`: تحويلات محافظة على أبعاد المدخلات (Slide 31)
تطبق الدالة تحويلاً مع ضمان إرجاع مخرجات تمتلك **نفس عدد صفوف المدخل الأصلي تماماً**، وهي أساسية جداً لعمليات التقييس الإحصائي (مثل حساب Z-score):
```python
df = pd.DataFrame({
    "salary": [5000, 4000, 6000]
})

# حساب الدرجة المعيارية Z-Score:
df["salary_z"] = df["salary"].transform(
    lambda s: (s - s.mean()) / s.std()
)
print(df)
#    salary  salary_z
# 0    5000  0.218218
# 1    4000 -0.872872
# 2    6000  0.654654
```

### 5. مقارنة ثلاثية منهجية: `map()` مقابل `apply()` مقابل `transform()` (Slide 32)

#### الحالة 1: مهمة بسيطة (مضاعفة القيمة عددياً):
```python
s = pd.Series([1000, 2000, 3000])
s.map(lambda x: x * 2)        # تعطي: 2000, 4000, 6000
s.apply(lambda x: x * 2)      # تعطي: 2000, 4000, 6000
s.transform(lambda x: x * 2)  # تعطي: 2000, 4000, 6000
```
تتطابق الدوال الثلاث في العمليات العددية البسيطة.

#### الحالة 2: حساب إحصائي يعتمد على كامل السلسلة (طرح المتوسط):
```python
s = pd.Series([1000, 2000, 3000])

# تنجح بامتياز لأنها تمرر كامل السلسلة وتحافظ على الأبعاد:
s.transform(lambda x: x - x.mean()) # الناتج: [-1000.0, 0.0, 1000.0]

# تفشل تماماً وتولد خطأ AttributeError: 'int' object has no attribute 'mean':
# s.map(lambda x: x - x.mean())
```

> [!important] القاعدة الذهبية للتفريق:
> * **`map()`**: تتعامل مع عنصر واحد في كل مرة. مثالية للقواميس والمطابقات الفردية.
> * **`apply()`**: أداة مرنة للمنطق البرمجي المشروط وتمرير الصفوف أو الأعمدة الكاملة.
> * **`transform()`**: مخصصة للعمليات الإحصائية التي ترجع نفس الشكل والأبعاد الأصلية.

### 6. الدالة `assign()`: إضافة أعمدة برمجية دون تعديل الجدول في مكانه (Slide 33)
تسمح بإضافة أو تحديث أعمدة وإرجاع إطار بيانات جديد مباشرة، مما يجعلها مثالية لتسلسل الدوال (**Method Chaining**):
```python
df = pd.DataFrame({
    "name": ["Ali", "Sara", "Omar"],
    "salary": [3000, 4000, 5000],
    "experience": [2, 5, 8]
})

result = df.assign(
    annual_salary=df["salary"] * 12
)
```

### 7. الدالة `pipe()`: تركيب خطوط أنابيب لمعالجة البيانات (Method Piping) (Slides 34 - 35)
تمكن من تمرير إطار البيانات كاملاً إلى دوال مستقلة مخصصة كحلقة في سلسلة العمليات:

```python
def add_annual_salary(data):
    return data.assign(annual_salary=data["salary"] * 12)

# الأسلوب النظيف والقابل للقراءة عبر .pipe():
result = (
    df.pipe(add_annual_salary)
    .query("experience >= 5")
    .sort_values("annual_salary", ascending=False)
)
print(result)
#    name  salary  experience  annual_salary
# 2  Omar    5000           8          60000
# 1  Sara    4000           5          48000
```

### 8. الدالتان التوأم: `where()` و `mask()` (Slides 36 - 37)

#### أ. الدالة `where(condition, other)`:
* **تحتفظ** بالقيم التي تحقق الشرط (`True`).
* **تستبدل** القيم التي لا تحقق الشرط (`False`) بالقيمة البديلة `other` (أو `NaN` إذا لم تُحدد):

```python
df = pd.DataFrame({
    "name": ["Ali", "Sara", "Omar"],
    "salary": [5000, 4000, 6000]
})

# الاحتفاظ بالراتب إذا كان >= 5000 واستبدال غير المؤهلين بـ 0:
df["eligible_salary"] = df["salary"].where(df["salary"] >= 5000, other=0)
print(df["eligible_salary"])
# 0    5000
# 1       0
# 2    6000
```

#### ب. الدالة `mask(condition, other)`:
* المعكوس المنطقي تماماً لـ `where`.
* **تستبدل** القيم التي تحقق الشرط (`True`) بالقيمة البديلة `other`.
* **تحتفظ** بالقيم التي تكون نتيجتها `False`:

```python
# وضع سقف أعلى للرواتب: أي راتب يتجاوز 5000 يتم استبداله بـ 5000:
df["capped_salary"] = df["salary"].mask(df["salary"] > 5000, other=5000)
print(df["capped_salary"])
# 0    5000
# 1    4000
# 2    5000
```

> [!tip] مفتاح الذاكرة الذهبي (Memory Rule):
> * `where` $\implies$ **تحفظ الـ True** وتستبدل الباقي.
> * `mask` $\implies$ **تقنع وتستبدل الـ True** وتحفظ الباقي.
