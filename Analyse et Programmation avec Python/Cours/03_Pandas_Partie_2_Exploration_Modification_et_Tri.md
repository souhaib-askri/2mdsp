## 1. استكشاف البيانات الجدولية (Exploration d'un DataFrame)

قبل الشروع في النمذجة أو المعالجة، يقتضي العمل التحليلي استكشاف الأبعاد والتوزيعات الإحصائية:

### أ. فحص الخصائص الهيكلية
* `df.shape`: إجمالي الأسطر والأعمدة.
* `df.size`: إجمالي عدد الخلايا المخزنة.
* `df.index` و `df.columns`: معرفة أسماء وتسميات المحاور.

### ب. الدوال الإحصائية والاستكشافية المدمجة
1. **دالة التوصيف الإحصائي `df.describe()`**:
   * تحسب للأعمدة الرقمية مقاييس النزعة المركزية والتشتت: المتوسط الحسابي ($\mu$)، الانحراف المعياري ($\sigma$)، والقيم الخمس الأساسية (الأدنى، الربعيات الثلاثة $Q_1, Q_2, Q_3$، والأقصى).
2. **توزيع التكرارات `Series.value_counts()`**:
   * تحسب عدد مرات تكرار كل قيمة فريدة في السلسلة.
   * يمكن تمرير `normalize=True` لحساب التكرار النسبي كنسب مئوية:
     ```python
     # حساب النسب المئوية لتوزيع الأحزاب
     elections["Party"].value_counts(normalize=True)
     ```
3. **القيم الفريدة `Series.unique()` و `Series.nunique()`**:
   * `s.unique()`: تعيد مصفوفة بالقيم الفريدة دون تكرار.
   * `s.nunique()`: تعيد عدد هذه القيم الفريدة كرقم صحيح.
4. **العينات العشوائية `df.sample(n, replace=False)`**:
   * سحب عينة عشوائية مكونة من $n$ صفاً لاختبار جودة البيانات أو لتطوير الأكواد المبدئية.

### ج. تقنية تتالي الدوال (Method Chaining)
تعتبر البرمجة المتتالية إحدى أقوى ممارسات Pandas لكتابة كود نظيف وقابل للقراءة دون توليد متغيرات وسيطة تملأ الذاكرة، ويُنصح دائماً بإحاطة التعبير بأقواس دائرية لتسهيل تقسيمه على أسطر متعددة:

```python
result = (
    babynames[babynames["Year"] == 2000]
    .sample(4, replace=True)
    .iloc[:, 2:]
)
```

## 2. تعديل الأعمدة والأسطر وإدارة نسخ الذاكرة (Modification & Copies)

### أ. إضافة وتعديل الأعمدة
```python
# حساب طول كل اسم وإضافته كعمود جديد
babynames["name_lengths"] = babynames["Name"].str.len()

# تعديل عمود موجود بضرب قيمه في معامل ثابت
df["salary"] = df["salary"] * 1.05
```

### ب. إعادة التسمية وحذف المتغيرات
* **إعادة تسمية الأعمدة**:
  ```python
  babynames = babynames.rename(columns={"name_lengths": "Length"})
  ```
* **حذف الأعمدة أو الأسطر عبر `.drop()`**:
  * تحذف الدالة الأسطر افتراضياً. لحذف الأعمدة، يجب تحديد `axis="columns"` (أو `axis=1`):
  ```python
  babynames = babynames.drop("Length", axis="columns")
  ```

> [!danger] قاعدة حاسمة: سلامة النسخ في الذاكرة (DataFrame Copies)
> دالة `.drop()` ومعظم دوال Pandas التحويلية **لا تعدل الكائن الأصلي في مكانه (Non-mutating by default)**؛ بل تنشئ وتعيد **نسخة جديدة معدلة** من إطار البيانات في الذاكرة. لذلك، فإن استدعاء:
> ```python
> babynames.drop("Length", axis="columns")
> ```
> لن يغير أي شيء في جدول `babynames`، وسيبقى العمود موجوداً ما لم نقم بإعادة إسناد الناتج الصريح:
> ```python
> babynames = babynames.drop("Length", axis="columns")
> ```

## 3. استراتيجيات الترتيب والفرز (Sorting Strategies)

تُعد إعادة ترتيب البيانات أمراً حيوياً لتحديد الأوائل، وتتبع مسارات الانتخابات والأسماء:

```python
# الترتيب التنازلي المباشر حسب تكرار الاسم
babynames.sort_values(by="Count", ascending=False)
```

عندما نريد فرز البيانات بناءً على **خاصية محسوبة** (مثلاً: ترتيب الأسماء حسب أطوالها، أو حسب عدد مرات ظهور مقطع صوتي معين)، يبرز أمامنا ثلاثة مسارات هندسية:

### الاستراتيجية 1: إنشاء عمود وسيط (Intermediate Column)
إنشاء عمود `name_lengths` ثم الترتيب به ثم حذفه. هذه الطريقة تستهلك ذاكرة إضافية وتتطلب خطوات تنظيف يدوية.

### الاستراتيجية 2: استخدام المعامل `key=lambda` (الأسلوب الأمثل والأنظف)
يقبل التابع `.sort_values()` وسيطاً يُدعى `key` يطبق دالة تحويلية على السلسلة مؤقتاً أثناء الفرز دون إنشاء أعمدة دائمة:
```python
# ترتيب الأسماء تنازلياً وفق طول الاسم دون أي عمود إضافي
babynames.sort_values(
    "Name", 
    key=lambda s: s.str.len(), 
    ascending=False
).head()
```

### الاستراتيجية 3: الترتيب بدوال الخرائط المخصصة `.map()`
عندما تتطلب معايير الترتيب خوارزمية مركبة (مثل البحث عن تكرار المقاطع `'dr'` و `'ea'` داخل الاسم):
```python
def dr_ea_count(text):
    return text.count('dr') + text.count('ea')

babynames["score"] = babynames["Name"].map(dr_ea_count)
babynames_sorted = babynames.sort_values(by="score", ascending=False)
```

## 5. صندوق أدوات التحويل المتقدم في Pandas (Transformation Toolkit)

يوفر Pandas منظومة متكاملة من الدوال لمعالجة البيانات. يلخص الجدول التالي الاستخدام الأمثل لكل دالة:

```
┌─────────────────┬───────────────────────────────┬────────────────────────────────────────────────────────┐
│ الدالة (Method) │ الكائن المستهدف (Target)      │ الغرض الرئيسي وحالة الاستخدام المثلى                   │
├─────────────────┼───────────────────────────────┼────────────────────────────────────────────────────────┤
│ Vectorized Ops  │ Series / DataFrame كامل       │ العمليات الرياضية المباشرة (+, -, *, /) (الأسرع مطلقاً) │
│ apply(axis=1)   │ DataFrame (سطر بسطر)          │ تطبيق شروط معقدة تعتمد على تفاعل عدة أعمدة             │
│ map(...)        │ Series فقط                    │ استبدال القيم عبر معاجم التشفير (Dictionary Lookup)    │
│ query(...)      │ DataFrame                     │ تصفية الأسطر عبر سلاسل نصية واضحة ومقروءة              │
│ transform(...)  │ Series / GroupBy              │ الحفاظ على شكل وأبعاد المصفوفة الأصلية (N ➔ N)        │
│ pipe(...)       │ DataFrame كامل                │ ربط خطوات المعالجة المعيارية في خط أنابيب متسلسل       │
│ where(...)      │ Series / DataFrame            │ الإبقاء على القيم المحققة للشرط واستبدال غير المحققة   │
│ mask(...)       │ Series / DataFrame            │ استبدال القيم المحققة للشرط والإبقاء على غير المحققة   │
└─────────────────┴───────────────────────────────┴────────────────────────────────────────────────────────┘
```

### أ. العمليات المتجهة (Vectorized Operations) - الخيار رقم 0
دائماً وأبداً، تُفضّل العمليات المباشرة على الأعمدة لأنها تستدعي خوارزميات C التحتية المحسنة:
```python
df["total"] = df["price"] * df["quantity"]
df["discounted"] = df["total"] * 0.90
df["large_order"] = df["total"] >= 50
```

### ب. دالة `apply(axis=1)` للحسابات المتقاطعة بين الأعمدة
تُستخدم عندما يعتمد الحساب في كل سطر على قيم متواجدة في أعمدة مختلفة:
```python
df["bonus"] = df.apply(
    lambda row: row["salary"] * 0.10 if row["experience"] >= 5 else row["salary"] * 0.05,
    axis=1
)
```

### ج. دالة `Series.map()` للتحويل بالمعاجم
حصرية للسلاسل، وتعتبر الأداة الأسرع لتحويل الفئات (Encoding):
```python
grade_points = {"A": 90, "B": 80, "C": 70}
df["points"] = df["grade"].map(grade_points)
# أي قيمة لا تجد تطابقاً في المعجم تتحول تلقائياً إلى NaN
```

### د. دالة `query()` للتصفية التعبيرية
```python
# كود مقروء جداً
result = df.query("salary >= 5000 and experience >= 5")
```

### هـ. دالة `transform()` والمقارنة المعيارية الثلاثية
تضمن دالة `transform()` أن تكون المخرجات **بنفس حجم وشكل المدخلات تماماً ($N \to N$)**، وتستخدم بكثرة في تقييس البيانات (Standardization):

$$Z = \frac{X - \mu}{\sigma}$$

```python
df["salary_z"] = df["salary"].transform(lambda s: (s - s.mean()) / s.std())
```

> [!question] المقارنة الجوهرية: `map` مقابل `apply` مقابل `transform`
> * في الحالات البسيطة (مثل مضاعفة قيم عمود `s * 2`)، تعطي الدوال الثلاث نفس النتيجة.
> * **نقطة الافتراق الحاسمة**:
>   * دالة `map` تعمل عنصراً بعنصر وتقتصر على السلاسل.
>   * دالة `apply` تسمح بتلخيص البيانات (Aggregation مثل استخراج المجموع أو المتوسط لتعيد قيمة واحدة).
>   * دالة `transform` ترفض التلخيص تماماً؛ إذا حاولت الدالة تقليص الحجم ستثير خطأ لأنها مصممة للحفاظ على المحاذاة الكاملة لكل سطر مدخل.

### و. المعالجة بالأنابيب `pipe()` وتعديل الحواف `where` و `mask`
* **دالة `pipe`**:
  ```python
  def calculate_tax(data, rate=0.19):
      return data.assign(tax=data["salary"] * rate)

  final_df = df.pipe(calculate_tax).query("salary > 4000")
  ```
* **دالتا `where` و `mask`**:
  * `where(condition, other)`: تحافظ على القيمة إذا تحقق الشرط، وتضع `other` إن لم يتحقق.
  * `mask(condition, other)`: تستبدل القيمة بـ `other` إذا تحقق الشرط، وتحافظ عليها إن لم يتحقق (متمم منطقي معكوس).
  ```python
  # تحديد سقف للرواتب (Capping) بحيث لا يتجاوز أي راتب 5000
  df["capped_salary"] = df["salary"].mask(df["salary"] > 5000, other=5000)
  ```
