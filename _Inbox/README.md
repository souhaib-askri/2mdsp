# مجلد الاستلام (_Inbox)

ضع هنا أي ملفات، محاضرات، تمارين، مشاريع، أو عروض تقديمية (PDF, PPTX, IPYNB, ZIP, إلخ).

بمجرد وضع الملفات:
- اطلب مني في المحادثة ترتيبها (مثال: "رتب الملفات الجديدة").
- أو يمكنك تشغيل السكربت التلقائي: `python3 organize.py`

سيتم فحص اسم ومحتوى كل ملف ونقله تلقائيًا إلى المجلد المناسب للمادة والمجلد الفرعي (`Cours` / `TP` / `TD`).
